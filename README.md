Foundly

Foundly is an AI-powered lost-and-found platform that helps people find lost items by matching reports of lost and found belongings.

Target users: University students, staff, and campus communities in Kazakhstan.

Problem:

Lost items are often reported across different chats and social media platforms. Finding a matching report is time-consuming, and many lost belongings never return to their owners.

Solution:

Foundly uses AI-assisted matching to connect lost and found item reports based on descriptions, categories, photos, and locations. Users can select their university, search campus-specific listings, and discover potential matches.

How it Uses Solana:

Foundly uses Solana Devnet to record item report metadata through the Memo Program.

When a user confirms a transaction with Phantom Wallet, the application writes a short memo containing the report type, category, item description, general location, and timestamp.

Network: Solana Devnet
Program: Memo Program
Wallet: Phantom
Transaction fees: Paid by the user's wallet using test SOL
Verification: Transactions can be viewed in Solana Explorer.

Blockchain records provide publicly verifiable timestamps and immutable records of submitted reports. They do not prove ownership or guarantee that an item has been recovered.

How to Run:

1. Clone or download the project.
2. Install the required dependencies.
3. Configure any required environment variables.
4. Start the development server using the commands specified in the project configuration.
5. Open the application in your browser.
6. Connect Phantom Wallet and switch to Solana Devnet.
7. Obtain test SOL from a Devnet faucet to submit blockchain transactions.
